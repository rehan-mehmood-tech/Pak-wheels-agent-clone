# PakWheels AI Assistant Clone 🚗🤖

An AI-powered conversational agent built to assist users with automotive queries, car inventories, filters, and recommendations, inspired by PakWheels.

## Features
* **AI-Driven Conversations:** Powered by LangChain and Groq LLM.
* **Smart Car Recommendations:** Helps users filter and find cars based on their preferences.
* **Interactive Interface:** Built for seamless deployment and user interaction.

## Tech Stack
* Python
* LangChain & Groq API
* Streamlit
